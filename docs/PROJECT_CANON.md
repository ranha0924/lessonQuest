## 1. 제품 정의

LessonQuest는 여러 교육 사이트를 모아 놓은 포털이 아니다.

> 선생님이 생성형 AI와 함께 플레이 가능한 배움의 세계를 만들고, 학생들이 그 안에서 미션·실험·탐험·추리·이야기·공동 보스를 플레이하며 배우는 플랫폼이다. Rasa는 정답 대신 학생이 스스로 답을 찾는 길을 안내하고, 교사는 학습 과정과 성장을 확인한다.

“교육의 로블록스”는 창작자가 체험을 만들고 사용자가 함께 플레이한다는 구조를 설명하는 비유다. Roblox 연동이나 3D 메타버스 구축을 뜻하지 않는다.

## 2. 네 제품 영역

1. **LessonQuest Studio** — 교사가 AI로 학습 체험을 생성·검증·수정·승인·배포한다.
2. **LessonQuest Play** — 학생이 과제와 체험을 실행하고 성장·협동한다.
3. **Rasa** — 현재 학습 맥락을 받아 단계적 힌트와 질문을 제공한다.
4. **Institution Console** — 교사·기관 관리자·플랫폼 운영자가 반, 사용자, 콘텐츠, 결과와 비용을 관리한다.

## 3. 제품 불변 조건

- AI 생성물은 독립 검증과 교사 승인 없이 게시하지 않는다.
- 승인된 체험은 덮어쓰지 않고 불변 버전으로 남긴다.
- 생성 코드는 인증 정보와 학생·기관 데이터에서 격리한다.
- 모든 기관 데이터는 `organizationId` 경계를 가진다.
- Rasa는 답안 생성기가 아니며 허용된 Action만 요청할 수 있다.
- 공동 보스 점수와 데미지는 서버가 검증한 학습 이벤트로 계산한다.
- 학생 간 공개 비교로 특정 학생을 창피하게 만들지 않는다.
- 기존 앱의 정상 배포와 저장소를 통합 작업 때문에 변경하거나 중단하지 않는다.
- 기존 저장소에서는 필요한 코드·기능·테스트만 출처를 기록해 `lessonQuest`로 선별 이식한다.
- 데이터 마이그레이션은 백업·검증·롤백 계획 없이 실행하지 않는다.

## 3.1 구현 전 검증 게이트

- 프로덕션 코드, 데이터베이스 마이그레이션, 배포 변경은 구체적인 계획을 먼저 작성한다.
- 계획은 `memory/projects/lessonquest.md`의 100점 기준표로 검증하고 근거와 점수를 `docs/reviews/`에 남긴다.
- 최종 점수가 **85점을 초과할 때만** 구현한다. 즉, 최소 통과 점수는 86점이다.
- 85점 이하면 계획을 보완하고 새로 검증하며, 통과 전에는 구현을 시작하거나 재개하지 않는다.
- 치명적 보안·개인정보·테넌트 격리·복구 불가 위험이 남아 있으면 총점과 무관하게 실패다.
- 게이트 통과 후에도 테스트 우선 개발과 전체 영향 범위 검증을 별도로 완료해야 한다.
- 구현이 끝나면 해당 구현에 참여하지 않은 독립 에이전트가 실제 변경 사항과 검증 근거를 최종 심사한다.
- 독립 최종 심사 역시 **85점을 초과해야** 하며, 최소 통과 점수는 86점이다.
- 최종 심사가 85점 이하이거나 치명적 결함이 있으면 완료로 인정하지 않고 수정한 뒤 새로운 독립 심사를 받는다.
- 독립 최종 심사를 통과하기 전에는 완료 선언, 병합, 배포를 하지 않는다.

## 4. 필수 저작 흐름

```text
교사 입력
  → AI 설계안·초안 생성
  → 별도 검증
  → 격리된 미리보기
  → 교사 수정·승인
  → 불변 버전 저장
  → 반에 배포
```

## 5. Phase 1 기준 흐름

```text
교사가 과학 개념 입력
  → AI가 개념·체험·퀴즈 생성
  → 별도 검증
  → 교사가 미리보고 승인
  → 반에 배포
  → 학생이 플레이
  → Rasa 힌트 요청
  → 학습 이벤트 저장
  → 검증된 행동이 공동 보스에 기여
  → 교사가 결과 확인
```

Phase 1은 이 한 흐름을 끝까지 완성하기 전 다른 과목과 결제·마켓플레이스·복잡한 기관 기능으로 확장하지 않는다.

## 6. 핵심 용어

- **Experience** — 학생이 실행하는 하나의 학습 체험 논리 단위
- **ExperienceVersion** — 내용과 실행물을 고정한 불변 버전
- **Manifest** — 체험의 ID, 버전, 과목, 학습 목표, 진입점, 권한과 기능 선언
- **LearningEvent** — 시작, 문항 응답, 힌트, 완료 등 학습 과정의 append-only 기록
- **Rasa Context** — 학생과 현재 학습 장면을 설명하는 최소 정보 묶음
- **Rasa Action** — 화면이 검증 후 실행할 수 있는 제한된 명령
- **Verified Contribution** — 서버가 검증한 학습 행동으로부터 계산된 XP·미션·보스 기여
