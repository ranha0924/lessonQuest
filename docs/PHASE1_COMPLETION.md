## 완료 범위

Phase 1의 대상은 과학 한 과목의 합성 데이터 기반 흐름이다. 실제 제작소와 학생 화면, API·인증·저장소의 기존 로직을 연결하며 생성 입력은 예제 JSON, Rasa는 결정론적 로컬 제공자다. 외부 생성 AI와 운영 인증·서버 DB를 연결한 상용 서비스 완성이라는 뜻은 아니다.

## 복구 및 제한

- 답안·완료·힌트의 저장 전 전송 실패와 저장 후 응답 유실을 실제 HTTP client → Hono → PGlite 경계에서 검사한다. 동일 ID 재전송은 효과를 중복시키지 않으며, 불확실한 요청 중에는 경쟁하는 기록을 막는다.
- 힌트 제공자 거절·실패·시간 초과·힌트 소진·소속 철회는 성공한 힌트나 허위 진행 기록을 만들지 않는다. 일반 최종 저장 실패는 권한 거절과 구분한다. 실패한 요청은 변경하지 않고, 복구 후 새 요청으로 같은 단계의 힌트를 받을 수 있다.
- 개발 미리보기의 인증 목록과 DB는 브라우저 소유자가 제어한다. 기존 tenant 검사 로직이 실행되더라도 실제 사용자 데이터를 보호하는 운영 서버 경계로 볼 수 없다.
- 데이터는 해당 탭의 메모리에만 있다. 역할을 바꾸면 유지되지만 초기화·새로고침으로 사라진다. Firebase, 실제 학생 데이터, 외부 AI, 유료 인프라를 사용하지 않는다.
- 힌트 처리 중 화면을 나갔다 돌아오면 서버가 처리 완료 전 이어하기를 잠시 거절한다. 처리 후 다시 이어하기를 누르면 저장된 힌트와 진행 상태를 읽는다. 복구 불가능한 저장 오류로 처리 중 상태가 남으면 안전하게 차단하며, 이 개발 환경에서는 데이터 초기화로 복구한다. 운영 작업자 중단 복구와 여러 기기의 동시 학습은 검증 범위 밖이다.
- Playwright 검증 엔진은 Chromium이다. 실제 PostgreSQL 다중 연결 경쟁, Safari/Firefox, 운영 백업·복구·모니터링은 이 범위의 통과 주장에 포함하지 않는다.
- 과학 체험은 현재 정해진 블록 렌더러다. 자유로운 게임 제작, 외부 AI 생성, 예측·실험·성찰의 풍부한 상호작용, 운영 기관 콘솔과 기타 과목은 후속 개발 대상이다.
